# 🦸‍♂️ TiendaComics - Sistema de Inventario

Un sistema interactivo por consola desarrollado en Java para gestionar el inventario y registro de productos de una tienda de cómics y figuras de acción. 

## 🚀 Características Principales
* **Registro Dinámico:** Permite ingresar datos de productos (ID, nombre, tipo, precio y stock) en tiempo real mediante teclado.
* **Flujo Continuo:** El sistema se mantiene activo registrando múltiples artículos a través de un bucle de control, hasta que el usuario decide finalizar el turno.
* **Almacenamiento en Memoria:** Utiliza estructuras de datos dinámicas para mantener un historial seguro de todos los productos registrados durante la sesión.
* **Catálogo Formateado:** Al cerrar el sistema, genera y muestra un resumen automático con todos los detalles de los artículos almacenados.

## 🛠️ Tecnologías y Conceptos Aplicados
* **Lenguaje:** Java
* **Paradigma:** Programación Orientada a Objetos (POO)
* **Estructuras de Datos:** `ArrayList`
* **Conceptos Técnicos Demostrados:** 
  * Clases, Objetos y Constructores.
  * Encapsulamiento de datos (modificadores `private`, métodos `get` y `set`).
  * Sobreescritura de métodos nativos (`@Override toString`).
  * Interactividad y limpieza de buffer de memoria usando la clase `Scanner`.
  * Control de flujo algorítmico mediante ciclos `while` y `for-each`.
  * * Manejo de excepciones y prevención de errores del sistema mediante bloques `try-catch` para validar la entrada de datos numéricos.
